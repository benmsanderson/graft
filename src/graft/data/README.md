# Data shipped with graft

- `phbio.average.7states.txt`: GLM's probability of harvest given stand
  biomass, 50 bins of 0.5 kg C/m2 (biomass upper bound, probability). From
  the CMIP6 GLM source (University of Maryland; Hurtt et al. 2020, GMD 13,
  5425-5464), used unchanged by `graft.extend` to weigh secondary forest for
  harvest after 2150. GLM's source carries no licence file; cite Hurtt et al.
  2020 when using it.
