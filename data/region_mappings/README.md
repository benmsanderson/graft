# Region mappings

Country (ISO3) to common region, one file per marker model and region set,
in the `region,country` shape mrdownscale's COFFEE path reads as a
`regionMapping`. Region names match the `Region` column of the ScenarioMIP
IAMC releases, so each file joins directly to that model's data.

Generated by `scripts/region_masks.py` from
[IAMconsortium/common-definitions](https://github.com/IAMconsortium/common-definitions)
(CC0-1.0) at commit `e31d467`:

```
python scripts/region_masks.py R10 --data land_r10.csv \
    --write data/region_mappings --models "REMIND-MAgPIE 3.5-4.11"
```

A model is written here only after its reported 2020 land passes the
area check against the countries its mapping assigns.

| File | Area check (reported / mapped land) |
|---|---|
| `REMIND-MAgPIE_3.5-4.11_R10.csv` | 10 of 11 regions within 6%; Pacific OECD (Japan alone) 12%, 4 Mha |

Kosovo is `XKX`, the World Bank code; ISO 3166 has none. Check how the
consuming country list treats it (some fold it into Serbia) before joining.
